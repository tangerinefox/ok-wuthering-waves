# docs/characters/ —— 角色技能原文

从数据站抓下来的**角色技能文本**，一个角色一个目录。

---

## 为什么要放在这儿

技能文本是写盲打段的**原始依据**——哪个技能算什么伤害、什么时候解锁、持续几秒、
什么条件下能放，全靠它。

放在仓库里，接手的人（或 AI）读代码时能**顺手对照**，不用满世界找。之前这些文件
放在仓库外面，clone 代码根本拿不到，等于没有。

## 命名规范

```
{角色ID}-{角色名}/
    技能属性-中文.txt       技能、属性、共鸣链（不含剧情）
    全量含故事-中文.txt     上面全部 + 五篇背景故事 + 语音 + 珍视之物
    prydwen攻略-英文.txt    英文攻略站的机制解析、循环概念、面板目标
```

角色 ID 用 encore.moe 的编号（**心 = 1311**）。

## 数据来源

**encore.moe** —— `https://encore.moe/character/{ID}?lang=zh-Hans`

官方数据站，技能文本最全，**而且有中文**。这个是主力来源。

**Prydwen** —— `https://www.prydwen.gg/wuthering-waves/`

英文攻略站。它给的不是原始数据，是**已经消化过的东西**：机制解析、循环概念、
面板数值目标、配队建议。技能文本给"是什么"，它给"怎么用"。

## 抓取流程

完整步骤和踩过的坑都写在 **`docs/文本抓取流程.md`** 里。抓新角色之前先读那个。

几个最容易卡住的点，提前说：

- encore.moe 的中文参数是 **`?lang=zh-Hans`**。试 `zh`、`cn`、`zh-cn` 全都无效，
  而且**不报错**，页面照常显示英文——很容易以为自己看错了
- 网站**只翻译正文**，区块标题和字段名还是英文（`Forte Examination Report`、
  `Stories`、`Birthday:`、`MATERIALS` 这些），抓下来得自己做替换
- **图片上的字会丢**。按键图标（鼠标左键 / E / R）在纯文本里是空白，
  得读 `<img>` 的 `alt` 属性补回来
- 页面上的机制示意图是**空占位符**（`placeholder.png`），站点作者没上传真图，别指望它

## 抓新角色的清单

1. 拿角色 ID，打开 `https://encore.moe/character/{ID}?lang=zh-Hans`
2. 按 `文本抓取流程.md` 里的方法提取（替换图片 → 取 innerText → 还原）
3. 扫一遍纯英文行，替换成中文
4. 切成两份：技能属性版 / 全量版
5. 去 Prydwen 抓一份攻略页
6. 按上面的命名规范放进 `docs/characters/{ID}-{名字}/`
7. 顺手在 `HANDOFF.md` 的进度里提一句
